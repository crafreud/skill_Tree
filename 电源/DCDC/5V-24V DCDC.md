# 5V → 24V DCDC 升压转换器

## 1. 概述

5V 转 24V 是一种常见的 **Boost（升压）** 拓扑应用场景。典型用途包括：

- USB 5V 供电 → 24V 工业传感器/执行器
- 锂电池 3.7~4.2V 升压 → 24V LED 驱动
- 单片机系统 5V 母线 → 24V 通信接口（RS485、CAN 收发器）

> [!tip] 关键指标
> - 输入电压：4.5V ~ 5.5V（USB 供电）或 3.0V ~ 4.2V（锂电池）
> - 输出电压：24V（±2%）
> - 输出电流：典型 0.5A ~ 2A
> - 效率目标：> 85%

---

## 2. 拓扑选择

| 拓扑 | 升压比 | 复杂度 | 适用场景 |
|------|--------|--------|----------|
| **Boost（异步）** | ≤ 10:1 | 低 | 轻载、成本敏感 |
| **Boost（同步）** | ≤ 10:1 | 中 | 效率优先 |
| **SEPIC** | 任意 | 中 | 输入可高于或低于输出 |
| **Flyback** | 任意 | 高 | 需要隔离 |

本方案选择 **异步 Boost 拓扑**，原因：
- 5V→24V 升压比约 4.8:1，在 Boost 舒适工作范围内
- 电路简单，BOM 成本低
- 异步方案在 24V 输出时，二极管正向压降占比小（~3%），同步收益有限

---

## 3. 工作原理

### 3.1 基本电路

```
        L (电感)
  ┌────┤►├────┬─────────── Vout (24V)
  │            │
 Vin         D (肖特基二极管)
 (5V)          │
  │            │
  ├────[MOS]───┘
  │     │
  └─────┘
        │
       GND
```

### 3.2 工作阶段

**阶段 1：MOSFET 导通（ON）**
- 电流流过电感 L，电感储能
- 电感电流线性上升：$V_{in} = L \cdot \frac{di}{dt}$
- 二极管 D 反偏，负载由输出电容供电

**阶段 2：MOSFET 关断（OFF）**
- 电感电流不能突变，产生反向电动势
- 电感电压叠加输入电压，通过二极管向输出端供电
- $V_{out} = V_{in} + V_L$

---

## 4. 关键参数计算

### 4.1 占空比

$$D = 1 - \frac{V_{in}}{V_{out}} = 1 - \frac{5}{24} \approx 0.792$$

> [!warning] 高占空比注意
> 占空比接近 80%，对 Boost IC 的最大占空比有要求，选型时需确认 D_max ≥ 85%。

### 4.2 电感选择

**电感纹波电流**（通常取输出电流的 30%~40%）：

$$\Delta I_L = \frac{V_{in} \cdot D}{f_{sw} \cdot L}$$

以 $f_{sw} = 500kHz$，$I_{out} = 1A$ 为例：

$$L = \frac{V_{in} \cdot D}{f_{sw} \cdot \Delta I_L} = \frac{5 \times 0.792}{500k \times 0.4} = 19.8 \mu H$$

**选型建议**：选择 **22µH** 标准值，饱和电流 ≥ 1.5 × 峰值电流。

| 参数 | 计算值 | 建议 |
|------|--------|------|
| 电感值 | 19.8µH | 22µH |
| 峰值电流 | 1.2A | 饱和电流 ≥ 1.8A |
| DCR | — | ≤ 100mΩ |

### 4.3 输出电容

$$C_{out} \geq \frac{I_{out} \cdot D}{f_{sw} \cdot \Delta V_{out}}$$

假设纹波要求 $\Delta V_{out} = 50mV$：

$$C_{out} \geq \frac{1 \times 0.792}{500k \times 0.05} = 31.7 \mu F$$

**建议**：使用 2~3 颗 **22µF/35V MLCC** 并联，加一颗 **100µF/35V 电解电容** 稳压。

### 4.4 二极管选择

| 参数 | 要求 | 推荐型号 |
|------|------|----------|
| 反向电压 | ≥ 30V（1.25× 余量） | SS34、SS54 |
| 正向电流 | ≥ 1.5A | — |
| 正向压降 | ≤ 0.5V | 肖特基优先 |
| 反向恢复 | 越小越好 | 肖特基天然优势 |

### 4.5 MOSFET 选择

| 参数 | 要求 |
|------|------|
| V_DS | ≥ 30V |
| I_D | ≥ 2A（连续） |
| R_DS(on) | ≤ 50mΩ |
| Q_g | ≤ 20nC（高频开关） |

## 5. 推荐 IC 方案

### 方案 A：TPS61088（TI）

- 输入范围：2.7V ~ 12V
- 输出最高：12.6V（**需外接 MOSFET 扩展**）
- 开关频率：200kHz ~ 2MHz
- 内置 11A 开关 MOSFET

### 方案 B：LM5122（TI）⭐ 推荐

- 输入范围：3V ~ 65V
- 输出最高：65V
- 开关频率：100kHz ~ 1MHz
- 外置 MOSFET，灵活设计
- 适合 5V→24V 大功率场景

### 方案 C：MT3608（MORNSUN / 国产替代）

- 输入范围：2V ~ 24V
- 输出最高：28V
- 开关频率：1.2MHz 固定
- 内置 MOSFET，SOT23-6 封装
- 适合小功率（< 2W）低成本方案

> [!note] 选型建议
> - **小功率 (< 2W)**：MT3608，简单便宜
> - **中功率 (2~10W)**：LM5122 + 外置 MOS
> - **大功率 (> 10W)**：LM5122 / LM5170，多相并联

## 6. 典型电路设计（基于 LM5122）

### 6.1 原理图要点

```
Vin (5V) ─┬── C_in ── GND
           │
           └── L ──┬── SW ── LM5122
                   │
                 D (SS34)
                   │
                   ├── C_out ── GND
                   │
                 R_fb_top
                   │
                 Vout (24V) ── R_fb_bot ── GND
```

### 6.2 反馈电阻网络

$$V_{out} = V_{ref} \times \left(1 + \frac{R_{top}}{R_{bot}}\right)$$

LM5122 的 $V_{ref} = 1.225V$：

$$\frac{R_{top}}{R_{bot}} = \frac{24}{1.225} - 1 = 18.6$$

取 $R_{bot} = 10k\Omega$，则 $R_{top} = 186k\Omega$（用 180k + 6.2k 串联精确调整）。

## 7. PCB 布局要点

> [!danger] 布局是成败关键
> Boost 电路的 PCB 布局直接影响 EMI、效率和稳定性。

### 7.1 关键环路

**最小化高频电流环路面积**：

```
  C_in (+) ──→ MOSFET Drain
     ↑              │
     │           MOSFET Source
     │              │
  C_in (-) ←── L ──┘
```

这个环路在每个开关周期都会瞬间导通/关断，面积越小 EMI 越低。

### 7.2 布局规则

| 规则 | 说明 |
|------|------|
| 输入电容紧靠 IC | 距离 ≤ 3mm |
| 电感到 SW 引脚 | 走线短粗，减少寄生电感 |
| 二极管到输出电容 | 短直路径 |
| 反馈走线 | 远离开关节点，走线细且短 |
| 接地 | 功率地和信号地分开，单点汇合 |
| 散热 | MOSFET 和二极管下方铺铜，加散热过孔 |

### 7.3 层叠建议（4 层板）

| 层 | 用途 |
|----|------|
| Top | 信号 + 功率器件 |
| L2 | 完整地平面 |
| L3 | 电源平面（Vin / Vout） |
| Bottom | 信号 + 散热过孔 |

## 8. 调试与测试

### 8.1 上电前检查

- [ ] 检查焊接质量，特别是 QFN/DFN 引脚
- [ ] 确认反馈电阻分压比正确
- [ ] 输入端串联 1Ω 电阻限流保护
- [ ] 示波器探头接好，触发设置为单次

### 8.2 上电调试步骤

1. **低压空载测试**：输入 3V，观察输出是否正常升压
2. **逐步加压**：3V → 4V → 5V，观察波形
3. **轻载测试**：接 24V/100mA 假负载
4. **满载测试**：逐步加到额定电流
5. **效率测试**：记录 $P_{in}$ 和 $P_{out}$

### 8.3 常见问题

| 现象 | 可能原因 | 解决方法 |
|------|----------|----------|
| 输出电压偏低 | 占空比不够 / 电感饱和 | 检查 IC D_max / 更换大电感 |
| 输出纹波过大 | ESR 过高 / 布局不良 | 并联 MLCC / 优化布局 |
| MOSFET 过热 | R_DS(on) 太大 / 驱动不足 | 更换低阻 MOS / 检查驱动 |
| 无法启动 | 输入欠压 / 软启动异常 | 检查 UVLO 设置 / CSS 电容 |
| EMI 超标 | 环路面积大 / 无 snubber | 优化布局 / 加 RC snubber |

---

## 9. 效率优化技巧

1. **降低开关频率**：减少开关损耗，但电感体积增大
2. **选择低 R_DS(on) MOSFET**：导通损耗是主要损耗来源
3. **使用低正向压降肖特基**：或改用同步整流
4. **电感 DCR 要低**：铜损占总损耗 10~20%
5. **多层 PCB 铺铜**：降低走线电阻和寄生参数

> [!abstract] 总结
> 5V→24V Boost 设计的核心要点：
> 1. **选对 IC**：确认最大占空比覆盖 80%
> 2. **算对参数**：电感值、峰值电流、电容 ESR
> 3. **做好布局**：最小化高频环路面积
> 4. **耐心调试**：低压空载开始，逐步加压加载
